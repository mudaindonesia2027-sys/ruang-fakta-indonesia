# CMS Editorial Blueprint

## Modules
- Overview
- Articles
- Issues
- Review Queue
- Discussions / Moderation
- Source Library
- Corrections
- Settings

## Editorial workflow
Draft
→ Submit for Review
→ Editorial Review
→ Fact Check / Source Review
→ Approved
→ Published
→ Updated or Corrected
→ Archived

## Core principles
1. Editorial and advertising operations are separated.
2. Source relationships are stored with content.
3. Significant changes are auditable.
4. Corrections preserve explanations.
5. Verification state is visible in the issue domain.
6. UI permission checks must be backed by server-side authorization.
